Privacy by design

The model stays on the volunteer's device.

AI Palm never uploads the model or its API key. The app makes an outbound connection, runs the request locally, and returns only the result.

↗Outbound connection onlyNo router port forwarding is required.
1One task per GPUBusy devices are reserved until the task finishes.
⌁Credentials stay localYour local API key is never published.
